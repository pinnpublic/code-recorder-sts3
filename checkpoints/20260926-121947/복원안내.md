# 복원 지점

사용자가 "지금 버전 언제든 돌아갈 수 있게 기억해"라고 지정한 상태입니다.

- source-and-release.zip: 당시 player, plugin, feature, scripts, tests, 문서 및 최신 개별 배포 파일.
- viewer-settings.json: 사용자 스크린샷에서 확인한 설정. 브라우저 저장소를 직접 추출한 파일은 아닙니다.
- SHA256.txt: 백업 ZIP의 무결성 확인용 해시.

## 기준 상태

- STS3 분위기의 첫 화면과 파일 열기.
- 옵션별 테두리와 비활성 영역 표시.
- 자동 보기 / 한 단계씩 보기, 독립된 파일 전환 안내 단계.
- 한글 조합과 import 자동 재생 묶기.
- 스페이스바 계속하기, 파일 화면으로 이동한 후 코드 입력 전 대기.
- 전환 안내 표시 시간 1~5초 (기본 2초), 코드 입력 전 대기 0~5초 (기본 1초).
- localStorage 설정 기억, 타임라인 진행·남은 예상 시간.
- 작업 줄 아래 200px 여유.
- 플러그인 버전 0.2.2. 현재 웹 뷰어는 플러그인 배포 후 추가 수정된 상태입니다.

## 복원 방법

1. 복원 전 현재 파일을 별도로 백업합니다.
2. source-and-release.zip을 새 폴더에 풀면 당시 상태를 그대로 확인할 수 있습니다.
3. 뷰어만 복원할 때는 압축 속 player 폴더 전체를 사용합니다. 파일 목록이 달라질 수 있으므로 기존 폴더와 섞지 않습니다.
4. 전체 개발 상태는 압축 속 소스 폴더와 문서를 사용합니다. build와 실제 녹화 파일, STS 설치 및 워크스페이스는 백업 대상이 아닙니다.
5. 브라우저 옵션까지 맞추려면 viewer-settings.json 값을 localStorage 키 code-recorder.viewer.settings.v1에 저장한 뒤 새로고침합니다. 이 작업은 현재 브라우저 옵션을 덮어쓰므로 복원 요청 시에만 수행합니다.

이 백업은 변경하지 않고 보존합니다. 사용자가 이 복원 지점으로 돌아가자고 하면 해당 ZIP을 기준으로 복원합니다.
