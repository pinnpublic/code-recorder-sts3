Code Recorder for STS3

Record code edits and file changes in Spring Tool Suite 3 and export recordings as JSON.

Install

Open Help → Install New Software → Add and enter this update site:

https://pinnpublic.github.io/code-recorder-sts3/updates/

Select Code Recorder for STS3, complete installation and restart the IDE.

Version 0.2.6. Target: Spring Tool Suite 3.9.18.RELEASE / Eclipse 4.21 / Windows / Java 11.

Record

Open Window → Show View → Other → Code Recorder. Select a project or folder, start recording, then use Stop / Export to save the recording.
